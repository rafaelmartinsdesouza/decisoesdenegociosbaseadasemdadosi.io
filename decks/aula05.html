SVM linear e margem suave

  • Classificação de margem larga
  • Vetores de suporte e sensibilidade à escala
  • Margem rígida, margem suave e o parâmetro C

A ideia central

Encontrar a rua mais larga possível entre as classes.

Um SVM linear separa as classes com um hiperplano que maximiza a distância até as instâncias mais próximas de cada lado. Isso se chama classificação de margem larga.

Aula 5 · SVMs · 5

Desenhe no quadro: várias retas separam as classes, mas a do SVM fica o mais longe possível das instâncias de treino, o que tende a generalizar melhor.

SVM linear

Large margin classification

Hiperplano de decisão

wᵀx + b = 0

  • Divide o espaço de atributos em duas regiões
  • Determinado pelos vetores de suporte

Vetores de suporte

As instâncias da borda

  • As mais próximas da fronteira de decisão
  • As únicas que definem o hiperplano
  • Instâncias além da margem não alteram o modelo

Sensibilidade à escala

Escale sempre

  • Com escalas diferentes, a rua fica achatada
  • Aplique StandardScaler antes de treinar
  • Pipeline: StandardScaler, depois LinearSVC

Aula 5 · SVMs · 6

Margem rígida e margem suave

Quando os dados não são perfeitamente separáveis

Margem rígida

Hard margin

  • Exige separação linear perfeita
  • Só funciona se os dados forem linearmente separáveis
  • Muito sensível a outliers: um ponto fora do lugar muda tudo
  • Raramente usada na prática

Margem suave

Soft margin

  • Permite que algumas instâncias violem a margem
  • Variáveis de folga ζᵢ ≥ 0 medem a violação de cada ponto
  • Objetivo: minimizar ½‖w‖² + C Σ ζᵢ
  • Equilibra largura da rua e violações

Aula 5 · SVMs · 7

Com um outlier dentro da outra classe, a margem rígida nem é possível; com um outlier perto da fronteira, ela fica muito estreita e generaliza mal.

O parâmetro C

O trade-off entre margem larga e erros, controlado por você

C grande

Penalidade alta para violações

  • O modelo tenta classificar quase todos os pontos corretamente
  • Margem mais estreita, perto da margem rígida
  • Maior risco de sobreajuste
  • Use quando os dados têm pouco ruído

C pequeno

Penalidade baixa

  • Permite mais violações da margem
  • Margem mais larga, modelo mais generalista
  • Mais tolerância a outliers e ruído
  • Risco de subajuste em dados bem separados

O algoritmo calcula cada ζᵢ automaticamente no treino, junto com os pesos w e o intercepto b. Se o SVM sobreajusta, reduza C.

Aula 5 · SVMs · 8

SVM linear no código

Detectando Iris virginica

from sklearn.svm import LinearSVC
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
 
X = iris.data[["petal length (cm)",
               "petal width (cm)"]].values
y = (iris.target == 2) # Iris virginica
 
svm_clf = make_pipeline(StandardScaler(),
                        LinearSVC(C=1, random_state=42))
svm_clf.fit(X, y)
 
svm_clf.predict([[5.5, 1.7], [5.0, 1.5]])
svm_clf.decision_function([[5.5, 1.7], [5.0, 1.5]])

Sem probabilidades

Ao contrário da logística, o SVM linear não estima probabilidades: decision_function mede a distância assinada à fronteira.

C = 1 contra C = 100

No livro, C = 1 dá uma rua mais larga com mais violações e provavelmente generaliza melhor.

Margem e generalização

Por que a rua larga ajuda

Menos sensível

Ao ruído do treino

A fronteira depende de poucas instâncias, as da borda, e não da massa de dados.

Mais folga

Para dados novos

Uma instância nova perto da fronteira ainda cai do lado certo da rua.

Sem probabilidades

Só escores

SVC(probability=True) calibra probabilidades com validação cruzada interna, a um custo de treino maior.

SVM não linear

Quando os dados não são linearmente separáveis

01

Adicionar atributos polinomiais

PolynomialFeatures(degree=3) cria atributos como x₁², x₁x₂ e x₂², que tornam possíveis fronteiras curvas. Combine com LinearSVC num pipeline.

02

O problema com polinômios

Grau baixo não captura padrões complexos; grau alto gera uma explosão combinatória de atributos e deixa o treino lento.

03

A solução: o truque do kernel

Obtém o mesmo resultado de adicionar atributos polinomiais, sem criá-los. Matematicamente equivalente, muito mais eficiente.

Atributos polinomiais

O dataset das luas

from sklearn.datasets import make_moons
from sklearn.preprocessing import PolynomialFeatures
 
X, y = make_moons(n_samples=100, noise=0.15,

polynomial_svm_clf.fit(X, y)

make_moons

Duas meias-luas entrelaçadas: um conjunto de brinquedo para classificação binária não linear.

O resultado

Uma fronteira curva que acompanha as luas, com um modelo linear nos atributos expandidos.

Aula 5 · SVMs · 13

Truque do kernel

Kernel polinomial

K(a, b) = (γ aᵀb + r)ᵈ

Grau d (degree)

Grau do polinômio. d = 3 é um bom ponto de partida; d alto deixa o modelo mais complexo e mais lento.

coef0 (r)

Controla a influência dos termos de grau alto contra os de grau baixo. Com r = 0, só os termos de grau alto importam.

C

Regularização, com o mesmo papel da margem suave. Ajuste d, r e C juntos com GridSearchCV.

Aula 5 · SVMs · 14

Código do livro: SVC(kernel="poly", degree=3, coef0=1, C=5) num pipeline com StandardScaler. Se o modelo sobreajusta, reduza o grau; se subajusta, aumente.

Kernel polinomial no código

SVC com kernel="poly"

from sklearn.svm import SVC
 
poly_kernel_svm_clf = make_pipeline(
    StandardScaler(),
    SVC(kernel="poly", degree=3, coef0=1, C=5))
poly_kernel_svm_clf.fit(X, y)
 
# compare com grau 10 e coef0=100

Sem atributos novos

O kernel calcula o efeito dos termos polinomiais sem criá-los.

Ajuste

Sobreajuste: reduza o grau. Subajuste: aumente.

Busca

Comece com uma busca aleatória grossa e refine com uma grade em torno dos melhores valores.

Aula 5 · SVMs · 15

Atributos de similaridade

Outra forma de lidar com não linearidade

A ideia

Marcos (landmarks)

Para cada instância, mede-se a similaridade com alguns pontos de referência.

A função

RBF gaussiana

φ(x, ℓ) = exp(−γ ‖x − ℓ‖²): vai de 0, muito longe do marco, a 1, no próprio marco.

Exemplo do livro

Dados 1D com dois marcos

Com marcos em −2 e 1, cada x vira duas similaridades, e os dados passam a ser linearmente separáveis.

A forma mais simples de escolher marcos é usar cada instância como marco. Isso gera m atributos e só é viável com bases pequenas: o kernel RBF resolve esse custo.

Aula 5 · SVMs · 16

Kernel RBF gaussiano

K(a, b) = exp(−γ ‖a − b‖²)

γ grande, como 5

Sino estreito

  • Decai rápido com a distância
  • Cada instância influencia uma região pequena
  • Fronteira irregular e complexa
  • Risco de sobreajuste

γ pequeno, como 0,1

Sino largo

  • A influência se espalha por regiões maiores
  • Fronteira mais suave
  • Modelo mais simples, mais viés
  • Risco de subajuste

γ age como um hiperparâmetro de regularização. Se o modelo sobreajusta, reduza γ; se subajusta, aumente. Ajuste γ e C juntos com GridSearchCV.

Aula 5 · SVMs · 17

Código do livro: SVC(kernel="rbf", gamma=5, C=0.001) num pipeline com StandardScaler, comparando combinações de γ e C.

Kernel RBF no código

Combinando γ e C

rbf_kernel_svm_clf = make_pipeline(
    StandardScaler(),
    SVC(kernel="rbf", gamma=5, C=0.001))
rbf_kernel_svm_clf.fit(X, y)
 
# no livro: γ em {0,1; 5} e C em {0,001; 1000}
param_grid = {"svc__gamma": [0.1, 1, 5],
              "svc__C": [0.001, 1, 1000]}
grid = GridSearchCV(rbf_kernel_svm_clf,
                    param_grid, cv=3)

Quatro combinações

O livro compara γ pequeno e grande com C pequeno e grande nas luas.

O que se vê

γ grande deixa a fronteira irregular, contornando instâncias; γ pequeno a deixa suave.

Regressão SVM (SVR)

O objetivo invertido

A ideia

Encaixar o maior tubo possível

  • Colocar o máximo de instâncias dentro da rua
  • Limitar as instâncias fora dela
  • Instâncias dentro do tubo não afetam o custo: o modelo é ε-insensível

Hiperparâmetros

ε, C e kernel

  • ε: a largura do tubo de tolerância
  • ε maior: tubo mais largo, menos vetores de suporte, modelo mais simples
  • C: regularização, como no classificador
  • kernel: linear, poly ou rbf

SVR(kernel="rbf", C=100, epsilon=0.1, gamma=0.1) num pipeline com StandardScaler.

Por baixo dos panos

Função de decisão e margem

f(x) = wᵀx + b = w₁x₁ + … + wₙxₙ + b

ŷ = 0 se f(x) < 0; ŷ = 1 se f(x) ≥ 0

Largura da margem

A margem vale 2 / ‖w‖: maximizar a margem equivale a minimizar ‖w‖.

Forma convexa

Minimiza-se ½‖w‖², mais fácil de otimizar que ‖w‖.

Rótulos t⁽ⁱ⁾

Convenção: t = −1 para a classe negativa e t = +1 para a positiva.

Aula 5 · SVMs · 25

O problema primal

Margem rígida e margem suave

Rígida: min ½ wᵀw s.a. t⁽ⁱ⁾(wᵀx⁽ⁱ⁾ + b) ≥ 1 ∀i

Suave: min ½ wᵀw + C Σ ζ⁽ⁱ⁾ s.a. t⁽ⁱ⁾(wᵀx⁽ⁱ⁾ + b) ≥ 1 − ζ⁽ⁱ⁾, ζ⁽ⁱ⁾ ≥ 0

Programação quadrática

Problemas convexos com restrições lineares, resolvidos por solvers de QP.

Vetores de suporte

Instâncias na borda, com t⁽ⁱ⁾ f(x⁽ⁱ⁾) = 1; os multiplicadores de Lagrange αᵢ > 0 só para elas.

Remover outras instâncias

Não altera o modelo treinado.

Aula 5 · SVMs · 26

Outra forma de treinar SVMs lineares é o gradiente descendente na hinge loss, max(0, 1 − t), como faz o SGDClassifier.

Outra forma de treinar

Gradiente descendente na hinge loss

J(w, b) = ½ wᵀw + C Σᵢ max(0, 1 − t⁽ⁱ⁾(wᵀx⁽ⁱ⁾ + b))

Hinge loss

max(0, 1 − t): zero quando a instância está fora da rua e do lado certo; cresce linearmente com a violação.

SGDClassifier

Com loss="hinge", treina um SVM linear por gradiente: lento para convergir, mas escala e aprende online.

Squared hinge

Variante padrão do LinearSVC; mais sensível a outliers, converge mais rápido em bases limpas.

Aula 5 · SVMs · 27

O problema dual

A formulação que viabiliza o truque do kernel

max Σᵢ αᵢ − ½ Σᵢ Σⱼ αᵢ αⱼ t⁽ⁱ⁾ t⁽ʲ⁾ x⁽ⁱ⁾ᵀ x⁽ʲ⁾

s.a. αᵢ ≥ 0, Σᵢ αᵢ t⁽ⁱ⁾ = 0

Por que o dual

Mais rápido quando há menos instâncias que atributos; e só usa produtos internos entre instâncias.

Solução

ŵ = Σᵢ αᵢ t⁽ⁱ⁾ x⁽ⁱ⁾, com αᵢ > 0 só nos vetores de suporte.

Previsão

ŷ = sinal(Σᵢ αᵢ t⁽ⁱ⁾ K(x⁽ⁱ⁾, x) + b): nunca é preciso calcular φ(x).

Aula 5 · SVMs · 28

As condições KKT garantem que, para o SVM, primal e dual têm a mesma solução. Correção em relação ao slide original: o dual é mais rápido quando o número de instâncias é menor que o de atributos.

SVMs kernelizadas

Teorema de Mercer e os principais kernels

Teorema de Mercer: se K é positiva semidefinida, existe φ tal que K(a, b) = φ(a)ᵀφ(b). Não precisamos conhecer φ, apenas K.

KernelFórmulaQuando usar
LinearK(a, b) = aᵀbAtributos suficientes; equivale ao LinearSVC, porém mais lento
PolinomialK(a, b) = (γ aᵀb + r)ᵈDados não lineares; coef0 = r controla o viés do polinômio
RBF gaussianoK(a, b) = exp(−γ ‖a − b‖²)O mais popular; funciona bem em geral
SigmoideK(a, b) = tanh(γ aᵀb + r)Parecido com uma rede neural de uma camada oculta

Aula 5 · SVMs · 29

Com o kernel RBF, φ mapeia para um espaço de dimensão infinita: só o truque do kernel torna isso viável.

SVMs online e boas práticas

Dados grandes ou em fluxo contínuo

SVMs online

Treino incremental

  • SGDClassifier(loss="hinge") ≈ LinearSVC com SGD
  • partial_fit() para treino incremental
  • Útil quando a base não cabe na memória
  • Convergência mais ruidosa, mas escalável
  • Só fronteiras lineares, sem kernels

Boas práticas

Checklist

  • Sempre normalize com StandardScaler
  • Comece com LinearSVC ou SGDClassifier em bases grandes
  • Com cerca de 10 mil instâncias, tente SVC(kernel="rbf")
  • Ajuste C, γ (e o grau) juntos com GridSearchCV
  • Prefira C pequeno com dados muito ruidosos
