O que é um modelo de fundação

Um modelo grande, treinado em enormes volumes de dados, feito para servir de base reutilizável para muitas tarefas.

Linguagem, imagem, código e biologia já passaram por essa mudança. As séries temporais são a fronteira atual.

A mudança de paradigma

De um modelo por série a um modelo para todas

Antes

Um modelo específico

  • Uma LSTM ou um ARIMA treinado do zero para cada problema
  • Exige histórico suficiente de cada série
  • Muito tempo de modelagem

Agora

Um modelo base

  • Pré-treinado em dados não rotulados
  • Adapta-se a várias necessidades
  • Economiza tempo e recursos

Características essenciais

Três aspectos fundamentais

Escala

Bilhões de parâmetros

Pré-treinamento

Emergência

Capacidades não ensinadas

Resultados surpreendentes surgem à medida que os modelos crescem.

Os três modelos de referência

Todos lançados em 2024

Google

TimesFM

  • Cerca de 100 bilhões de pontos temporais no pré-treino
  • Transformer só com decoder
  • Lê a série em blocos (patches)
  • Previsões zero-shot

Amazon

Chronos

  • Baseado na arquitetura T5
  • Escala e quantiza a série em tokens
  • Trata a série como linguagem
  • Previsões probabilísticas

Salesforce

Moirai

  • Treinado no LOTSA: cerca de 27 bilhões de observações
  • Várias frequências
  • Qualquer número de variáveis
  • Previsões probabilísticas

Estratégias de aprendizado

Três formas de usar um modelo de fundação

Zero-shot

Sem adaptação

Aplica o modelo como está. Ideal com dados escassos e quando é preciso uma solução rápida.

Few-shot

Ajuste leve

Usa alguns exemplos do problema, melhorando a precisão sem grandes custos.

Fine-tuning

Retreino parcial

Retreina parte do modelo com dados próprios para o máximo desempenho na tarefa.

Aula 11 · Modelos de Fundação · 16

Limitações e cuidados

Revolucionários, mas não mágicos

Custo

Computacional alto

Modelos grandes exigem GPU e memória para inferência e ajuste.

Interpretação

Difícil

É difícil explicar por que o modelo previu um valor.

Vieses

Do pré-treino

Podem prejudicar a generalização em domínios muito específicos.

Sempre compare com um baseline ingênuo e com um modelo clássico, como na aula 10.

Aula 11 · Modelos de Fundação · 17

Quando usar modelos de fundação

Um guia prático para decisões

01

Dados escassos, tarefa genérica

Zero-shot: o pré-treino já conhece padrões universais.

02

Dados limitados, tarefa específica

Fine-tuning de um modelo de fundação para aprender as nuances do problema.

03

Muitos dados

Modelo especializado treinado do zero, para o máximo desempenho.

Mesmo com muitos dados, rode um modelo de fundação em zero-shot como baseline para medir o ganho do modelo próprio.
