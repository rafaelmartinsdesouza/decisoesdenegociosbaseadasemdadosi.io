Medida de desempenho

RMSE e MAE: duas normas para medir o erro

RMSE(X, h) = √( (1/m) Σ ( h(x⁽ⁱ⁾) − y⁽ⁱ⁾ )² )

MAE(X, h) = (1/m) Σ | h(x⁽ⁱ⁾) − y⁽ⁱ⁾ |

RMSE · norma ℓ2

A medida típica em regressão. Pesa mais os erros grandes.

MAE · norma ℓ1

Menos sensível a outliers. Útil quando há muitos valores extremos.

Notação

m instâncias, x⁽ⁱ⁾ os atributos da instância i, y⁽ⁱ⁾ o rótulo, h a função de previsão.

Aula 2 · Ponta a Ponta · 10

Quanto maior o índice da norma, mais ela se concentra nos valores grandes. Por isso o RMSE é mais sensível a outliers que o MAE.

Crie um conjunto de teste

Amostragem estratificada pela renda

housing["income_cat"] = pd.cut(
    housing["median_income"],
    bins=[0., 1.5, 3.0, 4.5, 6., np.inf],
    labels=[1, 2, 3, 4, 5])
 
strat_train_set, strat_test_set = train_test_split(
    housing, test_size=0.2,
    stratify=housing["income_cat"],
    random_state=42)

Por que estratificar

A renda mediana é um atributo muito importante. O teste precisa ter as mesmas proporções de cada faixa de renda que a população.

Amostragem aleatória

Pode distorcer as proporções por acaso, como uma pesquisa que entrevista mulheres demais.

Reprodutibilidade

Fixe random_state, ou use um hash do identificador para que o teste não mude ao atualizar os dados.

Limpeza dos dados

Valores ausentes com SimpleImputer

from sklearn.impute import SimpleImputer
 
imputer = SimpleImputer(strategy="median")
housing_num = housing.select_dtypes(
    include=[np.number])
imputer.fit(housing_num)
 
imputer.statistics_ # medianas aprendidas
X = imputer.transform(housing_num)

Três opções

Descartar os distritos, descartar o atributo ou imputar um valor, como a mediana.

Por que um imputer

Ele guarda a mediana do treino e aplica a mesma ao teste e aos dados novos.

Alternativas

KNNImputer e IterativeImputer usam outros atributos para estimar o valor ausente.

Aula 2 · Ponta a Ponta · 24

Atributos de texto e categóricos

Codificar ocean_proximity

OrdinalEncoder

Um inteiro por categoria

  • Simples, mas o modelo supõe que categorias próximas são parecidas
  • Bom para categorias ordenadas, como ruim, médio, bom

OneHotEncoder

Um atributo binário por categoria

  • Sem ordem artificial entre as categorias
  • Retorna uma matriz esparsa
  • handle_unknown="ignore" lida com categorias novas

Muitas categorias

Códigos de país, profissões

  • One-hot gera atributos demais
  • Use atributos numéricos relacionados ou embeddings

Aula 2 · Ponta a Ponta · 25

Os estimadores guardam feature_names_in_ quando recebem um DataFrame, e get_feature_names_out() ajuda a recuperar os nomes das colunas geradas.

Escala e transformação

Algoritmos de ML não gostam de escalas diferentes

Min-max

Normalização

Comprime os valores em [0, 1]. MinMaxScaler.

Padronização

Escore z

Média 0 e desvio-padrão 1. Menos sensível a outliers. StandardScaler.

Cauda pesada

Log ou raiz

Transforme antes de escalar para aproximar a distribuição de algo simétrico.

Multimodal

Kernel RBF

Similaridade a um valor de referência, como a idade de 35 anos.

Discretização

Buckets

Agrupe em faixas e trate como categorias.

Alvo

Transformar o rótulo

Use inverse_transform ou TransformedTargetRegressor para voltar à escala original.

Aula 2 · Ponta a Ponta · 27

Herdar TransformerMixin dá fit_transform() de graça; BaseEstimator dá get_params() e set_params(), úteis na busca de hiperparâmetros.

Pipelines de transformação

Encadeando tudo num só estimador

num_pipeline = make_pipeline(
    SimpleImputer(strategy="median"),
    StandardScaler())
 
cat_pipeline = make_pipeline(
    SimpleImputer(strategy="most_frequent"),
    OneHotEncoder(handle_unknown="ignore"))
 
preprocessing = ColumnTransformer([
    ("num", num_pipeline, num_attribs),
    ("cat", cat_pipeline, cat_attribs)])
 
housing_prepared = preprocessing.fit_transform(
    housing)

Pipeline

fit() chama fit_transform() em cada etapa e fit() na última.

ColumnTransformer

Aplica transformações diferentes a colunas numéricas e categóricas.

Vantagem

Reprodutibilidade e implantação: o pré-processamento viaja com o modelo.

Aula 2 · Ponta a Ponta · 28

Scikit-Learn

Princípios de design da API

Estimadores

fit(X, y)

Qualquer objeto que estima parâmetros a partir de dados, como um imputer.

Transformadores

transform(X)

Estimadores que também transformam dados, como StandardScaler e OneHotEncoder.

Preditores

predict(X) e score(X, y)

Estimadores que fazem previsões, como LinearRegression.

Outros princípios

Consistência

Inspeção (atributos com _ no fim), poucas classes novas, composição via pipelines e padrões sensatos.

Treine e avalie no conjunto de treino

O erro de treino engana nos dois sentidos

Regressão linear

Subajuste

  • RMSE de cerca de US$ 68 mil no treino
  • A maioria dos preços fica entre US$ 120 mil e US$ 265 mil: o erro é grande demais

Árvore de decisão

Sobreajuste

  • RMSE zero no treino
  • Bom demais para ser verdade: o modelo decorou os dados

Não toque no conjunto de teste ainda. Para avaliar de verdade, use validação cruzada.

Aula 2 · Ponta a Ponta · 32

O modelo linear subajusta: atributos insuficientes ou modelo fraco. A árvore sobreajusta. Os dois casos mostram por que precisamos de dados que o modelo não viu.

Avaliação melhor com validação cruzada

k-fold com cross_val_score

from sklearn.model_selection import cross_val_score
 
tree_rmses = -cross_val_score(
    tree_reg, housing, housing_labels,
    scoring="neg_root_mean_squared_error",
    cv=10)
 
pd.Series(tree_rmses).describe()

Como funciona

Divide o treino em 10 dobras e treina 10 vezes, validando em uma dobra diferente a cada vez.

O resultado

A árvore erra cerca de US$ 67 mil na validação, tanto quanto o modelo linear.

Floresta aleatória

Cerca de US$ 47 mil: bem melhor, mas ainda sobreajusta, pois o erro de treino é bem menor.

Aula 2 · Ponta a Ponta · 33

O Scikit-Learn espera uma função de utilidade (maior é melhor), por isso o RMSE vem negativo e trocamos o sinal.

Ajuste fino do sistema

Use o máximo de dados e automatize

Busca em grade

GridSearchCV

  • Testa todas as combinações de hiperparâmetros
  • Boa quando há poucos valores a explorar

Busca aleatória

RandomizedSearchCV

  • Sorteia combinações
  • Preferível com muitos hiperparâmetros ou espaços grandes

Otimização bayesiana

Para treinos longos

  • Usa priores de processo gaussiano para guiar a busca
  • Snoek et al., 2012

Ensembles

Combine os melhores

  • Os melhores modelos juntos costumam superar cada um
  • Funciona melhor quando erram de formas diferentes

Busca em grade

Ajustando a floresta dentro do pipeline

full_pipeline = Pipeline([
    ("preprocessing", preprocessing),
    ("random_forest",
     RandomForestRegressor(random_state=42))])
 
param_grid = [
  {"random_forest__max_features": [4, 6, 8]},
  {"random_forest__max_features": [6, 8, 10]}]
 
grid_search = GridSearchCV(
    full_pipeline, param_grid, cv=3,
    scoring="neg_root_mean_squared_error")
grid_search.fit(housing, housing_labels)
grid_search.best_params_

Nomes com __

Etapa e hiperparâmetro separados por dois sublinhados alcançam qualquer parâmetro do pipeline.

Resultados

best_params_, best_estimator_ e cv_results_ mostram tudo o que foi testado.

Busca aleatória

RandomizedSearchCV com n_iter e distribuições como randint; HalvingRandomSearchCV economiza tempo.
