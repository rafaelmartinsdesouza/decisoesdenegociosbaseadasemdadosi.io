Por que a acurácia não basta

Um classificador que nunca diz 5

~95%

acurácia do SGDClassifier na validação cruzada com 3 dobras

~91%

acurácia de um DummyClassifier que sempre responde “não é 5”

Só cerca de 10% das imagens são 5. Em classes desbalanceadas, a acurácia premia quem ignora a classe rara.

Implementando a validação cruzada

StratifiedKFold à mão

from sklearn.model_selection import StratifiedKFold
from sklearn.base import clone
 
skfolds = StratifiedKFold(n_splits=3)
for train_idx, test_idx in skfolds.split(
        X_train, y_train_5):
    clone_clf = clone(sgd_clf)
    clone_clf.fit(X_train[train_idx],
                  y_train_5[train_idx])
    y_pred = clone_clf.predict(X_train[test_idx])
    n_correct = sum(y_pred == y_train_5[test_idx])
    print(n_correct / len(y_pred))

Estratificação

Cada dobra mantém a proporção de cincos do conjunto completo.

clone()

Cria uma cópia não treinada do classificador a cada dobra.

Para que serve

Controle total sobre a avaliação, por exemplo para métricas próprias.

Precisão e revocação

Duas perguntas diferentes

Precisão = TP / (TP + FP)

Das previsões positivas, quantas estavam certas?

  • Alta precisão: poucos alarmes falsos
  • De todas as imagens previstas como 5, quantas eram 5?
  • Importa quando o falso positivo é caro: spam, vídeos seguros para crianças

Revocação = TP / (TP + FN)

Dos positivos reais, quantos foram encontrados?

  • Também chamada de sensibilidade ou taxa de verdadeiros positivos
  • De todas as imagens de 5, quantas foram detectadas?
  • Importa quando o falso negativo é caro: doenças, furtos em lojas

O detector de cincos tem precisão de cerca de 84% e revocação de cerca de 65%: quando diz 5, acerta 84% das vezes, mas só encontra 65% dos cincos.

Trade-offs e curvas

F1-score

A média harmônica de precisão e revocação

F1 = 2 × (precisão × revocação) / (precisão + revocação)

Média harmônica

Dá muito mais peso aos valores baixos: só é alta se as duas métricas forem altas.

Detector de cincos

F1 ≈ 0,73 com precisão de 84% e revocação de 65%.

Quando não basta

Às vezes você quer mais precisão ou mais revocação, não um equilíbrio.

Aula 3 · Classificação · 15

O F1 favorece classificadores com precisão e revocação parecidas. Nem sempre é isso que o problema pede.

O trade-off precisão/revocação

Aumentar uma geralmente reduz a outra

Limiar alto

Mais precisão, menos revocação

O modelo só diz positivo quando está muito confiante.

Limiar baixo

Mais revocação, menos precisão

Classifica mais casos como positivos, incluindo erros.

decision_function()

O escore de cada instância

Compare com o seu próprio limiar em vez de usar predict().

Curva precisão–revocação

Todos os limiares

precision_recall_curve() calcula as duas métricas para cada limiar.

Aula 3 · Classificação · 16

O SGDClassifier calcula um escore pela função de decisão. Se o escore passa do limiar, a instância vai para a classe positiva.

Escolhendo o limiar

Para 90% de precisão

y_scores = cross_val_predict(
    sgd_clf, X_train, y_train_5, cv=3,
    method="decision_function")
 
precisions, recalls, thresholds = \
    precision_recall_curve(y_train_5, y_scores)
 
idx = (precisions >= 0.90).argmax()
threshold_90 = thresholds[idx]
 
y_pred_90 = (y_scores >= threshold_90)
recall_score(y_train_5, y_pred_90) # ~0,48

Escores, não classes

method="decision_function" devolve os escores fora da amostra.

O custo

Para chegar a 90% de precisão, a revocação cai para cerca de 48%.

Escolha consciente

Escolha o limiar pelo objetivo de negócio, ou pelo maior F1.

A curva ROC

Receiver Operating Characteristic

O que é

TPR contra FPR

  • Taxa de verdadeiros positivos (revocação) contra taxa de falsos positivos
  • FPR = FP / (FP + TN): negativos classificados errado
  • Gerada variando o limiar de decisão
  • Perfeito: ponto (0, 1); aleatório: a diagonal

AUC

Área sob a curva

  • AUC = 1,0: classificador perfeito
  • AUC = 0,5: aleatório, inútil
  • Quanto maior, melhor
  • roc_auc_score() calcula direto

Aula 3 · Classificação · 19

A ROC também tem trade-off: quanto maior a revocação, mais falsos positivos.

ROC ou precisão–revocação?

Qual curva usar

Curva PR

Positivos raros

Prefira quando a classe positiva é rara ou quando os falsos positivos importam mais que os falsos negativos.

Curva ROC

Classes equilibradas

Pode parecer ótima mesmo com muitos falsos positivos quando os negativos dominam.

O exemplo do 5

A ROC engana

A AUC do SGD parece excelente, mas a curva PR mostra que ainda há muito a melhorar.

Classificação multiclasse

Distinguir mais de duas classes

OvR

Um contra o resto

  • Um classificador binário por classe
  • Escolhe a classe com maior escore
  • Padrão na maioria dos casos

OvO

Um contra um

  • Um classificador por par de classes
  • 10 classes: 10 × 9 / 2 = 45 classificadores
  • Bom para SVMs, que escalam mal

Nativa

Direto

  • Florestas, Naive Bayes, redes neurais
  • Vetor de probabilidade por classe
  • O sklearn escolhe OvR ou OvO sozinho

Aula 3 · Classificação · 24

No OvO cada classificador treina só com as duas classes que distingue, o que ajuda algoritmos como o SVM, que escalam mal com o tamanho da base.

Multiclasse no Scikit-Learn

OvO automático e OvR forçado

from sklearn.svm import SVC
svm_clf = SVC(random_state=42)
svm_clf.fit(X_train[:2000], y_train[:2000])
 
scores = svm_clf.decision_function(
    [some_digit]) # 10 escores, um por classe
 
from sklearn.multiclass import OneVsRestClassifier
ovr_clf = OneVsRestClassifier(SVC())
ovr_clf.fit(X_train[:2000], y_train[:2000])
len(ovr_clf.estimators_) # 10

SVC

Usa OvO por baixo: 45 classificadores binários.

Forçar a estratégia

OneVsRestClassifier ou OneVsOneClassifier.

Escalonar ajuda

Padronizar os pixels leva o SGD de cerca de 86% para 89% de acurácia.

Classificação multirrótulo

Vários rótulos binários por instância

O que é

Rótulos não exclusivos

  • Uma foto pode conter Alice e Bob ao mesmo tempo
  • No MNIST: o dígito é grande (7, 8 ou 9)? É ímpar?
  • A saída é um vetor binário, um valor por rótulo
  • KNeighborsClassifier suporta multirrótulo nativamente

Avaliação

Métricas por rótulo

  • F1 por rótulo, depois a média
  • Macro F1: média simples entre rótulos
  • F1 ponderado: pelo suporte de cada rótulo
  • Hamming loss: fração de rótulos errados

Classificação multissaída

Cada rótulo pode ter vários valores

O que é

Generaliza o multirrótulo

  • Exemplo: remover ruído de imagens
  • A entrada é a imagem com ruído; a saída, a imagem limpa
  • Cada pixel é uma saída com 256 valores possíveis
  • Também chamada de multiclasse multissaída

No Scikit-Learn

Implementação

  • KNeighborsClassifier().fit(X_train_noisy, X_train)
  • MultiOutputClassifier envolve qualquer classificador
  • Avaliação: RMSE por pixel ou por imagem
  • Útil em denoising, geração e segmentação
