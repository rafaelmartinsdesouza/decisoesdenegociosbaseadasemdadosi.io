A maldição da dimensionalidade

Em espaços de alta dimensão, a intuição falha: quase todo ponto é extremo e tudo fica longe de tudo.

Nós vivemos em três dimensões e não conseguimos imaginar um hipercubo de 1.000 dimensões. A matemática mostra comportamentos bem diferentes dos que esperamos.

Aula 8 · Redução de Dimensão · 5

Espaço quase vazio

A chance de um ponto aleatório estar perto da borda

Hipercubo unitárioChance de estar a menos de 0,001 da borda
2 dimensões (quadrado)0,4%
3 dimensões (cubo)0,6%
100 dimensões≈ 18%
10.000 dimensões> 99,999999%

A probabilidade é 1 − 0,998ᵈ. Em alta dimensão, quase todo ponto é extremo em alguma dimensão.

Correção em relação ao slide .pptx: o valor é cerca de 408,25, e não 408.000. Como cada ponto fica no máximo a √d do outro, o hipercubo de um milhão de dimensões tem diagonal 1.000.

Consequências

Por que isso importa para o ML

Dados esparsos

Instâncias muito afastadas

Uma instância nova fica longe de todas as de treino: prever vira extrapolar.

Dados necessários

Crescem exponencialmente

Com só 100 atributos em [0, 1], cobrir o espaço exigiria mais instâncias que átomos no universo observável.

Sobreajuste

Mais risco

Quanto mais dimensões, maior o risco de o modelo se ajustar ao ruído.

Projeção e manifold learning

As duas abordagens principais

Projeção

Um subespaço plano

  • Os dados ficam perto de um subespaço de dimensão menor
  • Projeta todos os pontos nele
  • Exemplo: o PCA projeta no hiperplano de máxima variância
  • Rápido, mas perde informação se os dados se dobram ou enrolam

Manifold learning

Uma variedade torcida

  • Hipótese do manifold: dados reais vivem numa variedade de baixa dimensão
  • Exemplo: o rolo suíço, uma variedade 2D enrolada em 3D
  • Objetivo: desenrolar a variedade
  • LLE, t-SNE, Isomap, MDS: mais expressivos, mais lentos

A hipótese do manifold vale para muitos dados reais, como imagens, texto e áudio: no MNIST, dígitos válidos ocupam uma fração minúscula do espaço de 784 dimensões.

PCA

Identifique o hiperplano mais próximo dos dados e projete os dados nele.

O PCA escolhe os eixos que preservam a maior variância, o que equivale a minimizar a distância quadrática média entre os dados e suas projeções.

Aula 8 · Redução de Dimensão · 13

Componentes principais

Eixos ortogonais, por ordem de variância

PC1

Máxima variância

  • Eixo que maximiza a variância projetada
  • Minimiza a distância média ao eixo
  • Encontrado pela SVD: X = U Σ Vᵀ

PC2

A variância restante

  • Máxima variância residual
  • Ortogonal ao PC1
  • E assim por diante: PC3, PC4...

Propriedades

O que garantir

  • Componentes ortogonais entre si
  • O PCA centraliza os dados
  • Número de componentes ≤ min(m, n)
  • Transformação linear

Aula 8 · Redução de Dimensão · 14

A direção de cada componente pode inverter de sinal entre execuções; o plano que eles definem é o mesmo.

Projetando em d dimensões

Multiplicar pela matriz dos d primeiros componentes

X_d-proj = X W_d

X_recuperado = X_d-proj W_dᵀ

W_d

As d primeiras colunas de V: os d primeiros componentes.

Centralização

Subtraia a média antes; o Scikit-Learn faz isso sozinho.

Reconstrução

Volta ao espaço original, com perda: o erro de reconstrução.

PCA no Scikit-Learn

Projetar, inspecionar e reconstruir

from sklearn.decomposition import PCA
 
pca = PCA(n_components=2)
X2D = pca.fit_transform(X)
 
pca.components_ # eixos (linhas)
pca.explained_variance_ratio_ # ex.: [0,758; 0,182]
 
X_back = pca.inverse_transform(X2D)

explained_variance_ratio_

No exemplo, o PC1 explica 75,8% e o PC2 mais 18,2%: 94% preservados.

inverse_transform

Reconstrução aproximada; o erro é proporcional à variância descartada.

n_components fracionário

PCA(n_components=0.95) preserva 95% da variância.

Escolhendo o número de dimensões

Variância suficiente sem perder demais

01

Plote a variância acumulada

Número de componentes no eixo x, variância acumulada no y. Procure o cotovelo.

PCA randomizado

Aproximação estocástica do PCA completo

Como usar

svd_solver

svd_solver="randomized". O padrão "auto" usa o randomizado quando a base é grande e d é bem menor que n.

Complexidade

Muito mais rápido

O(m × d²) + O(d³), contra O(m × n²) + O(n³) do SVD completo.

Resultado

Quase igual

Praticamente o mesmo do PCA exato. svd_solver="full" garante o exato.

PCA incremental

Para bases que não cabem na memória

from sklearn.decomposition import IncrementalPCA
 
n_batches = 100
inc_pca = IncrementalPCA(n_components=154)
for X_batch in np.array_split(X_train, n_batches):
    inc_pca.partial_fit(X_batch)
 
X_reduced = inc_pca.transform(X_train)

Quando usar

Base grande demais para a RAM, dados em fluxo ou treino online.

Como funciona

partial_fit acumula estatísticas de cada lote; batch_size ≥ n_components.

Alternativa: memmap

np.memmap trata um arquivo em disco como array; o IncrementalPCA lê por partes.

Projeção aleatória

Lema de Johnson–Lindenstrauss

d ≥ 4 log(m) / (ε²/2 − ε³/3)

A garantia

m pontos podem ser projetados para d dimensões preservando todas as distâncias com erro máximo ε, com alta probabilidade.

O surpreendente

d depende de m e de ε, não do número de atributos n.

Exemplo do livro

5.000 instâncias e ε = 10%: d ≥ 7.300, de 20.000 atributos.

Aula 8 · Redução de Dimensão · 23

sklearn.random_projection.johnson_lindenstrauss_min_dim(m, eps=0.1) calcula o d mínimo.

Projeção aleatória no Scikit-Learn

Duas classes

GaussianRandomProjection

Matriz gaussiana

  • n_components="auto" calcula d pelo lema
  • eps: erro máximo nas distâncias (padrão 0,1)
  • Muito mais rápida que o PCA em altíssima dimensão

SparseRandomProjection

Matriz esparsa

  • A maioria dos elementos é zero
  • Mais rápida e usa menos memória
  • Mesma garantia teórica
  • Ótima para texto, como TF-IDF

Útil como pré-processamento antes de algoritmos lentos em alta dimensão, como SVM e KNN.

LLE

Locally Linear Embedding: preservar relações locais

01

Encontrar vizinhos

Para cada ponto, os k vizinhos mais próximos (n_neighbors=k).

02

Reconstrução linear local

Pesos wᵢⱼ que reconstroem cada ponto pelos vizinhos, minimizando ‖xᵢ − Σ wᵢⱼ xⱼ‖².

03

Embedding de baixa dimensão

Uma representação em d dimensões que preserve os mesmos pesos.

LocallyLinearEmbedding(n_components=2, n_neighbors=10) desenrola o rolo suíço. Custo de O(m log m · n log k) a O(d m²): lento em bases muito grandes.
